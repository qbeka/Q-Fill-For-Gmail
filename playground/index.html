Q-Fill playground

Each page has a different kind of code field. Open one, send yourself an email such as Your verification code is 482913, then press Fill code in Q-Fill. The end-to-end tests run against these same pages.

  • Single field with autocomplete="one-time-code"
  • Six separate boxes with auto-advance and paste
  • One transparent input over six boxes
  • Framework-controlled input that ignores plain value changes
  • Login form with email, password and a code field
  • Field inside a shadow root
  • Field inside a same-origin iframe
  • A page with no code field

Serve this folder over http, for example with npx serve from the repository root, then open /playground/.
